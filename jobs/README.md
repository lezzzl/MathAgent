# Запуск задач на общей машине

Доступа к машине с картами ни у кого из студентов нет. Вместо этого вы
описываете запуск в маленьком YAML-файле и открываете PR. После вливания PR
диспетчер сам возьмёт задачу из очереди, дождётся свободных карт, выполнит
команду **из вашей ветки** и запушит результаты обратно в неё, а в PR напишет
комментарий с итогом.

## Как отправить запуск

**1. Запушьте свою ветку.** Имя должно начинаться с вашего префикса:
`Ilya/`, `Stas/`, `pavel/` или `Nikita/`.

```bash
git checkout -b Ilya/math500
git push -u origin Ilya/math500
```

**2. Добавьте спеку в `jobs/queue/`.** Имя файла становится `run_id` и именем
каталога результатов, поэтому оно должно быть уникальным:

```yaml
# jobs/queue/ilya-math500-temp07.yml
branch: Ilya/math500
command: python scripts/benchmarks/run_math500.py --limit 50 --temperature 0.7
gpus: 1
timeout_minutes: 60
```

**3. Откройте PR в `main` — только со спекой, без изменений кода.** Код живёт в
вашей ветке, на неё указывает поле `branch`.

**4. После вливания** ждите комментарий в PR. Результаты появятся в вашей ветке:

```bash
git pull origin Ilya/math500
ls results/runs/ilya-math500-temp07/
```

## Поля спеки

| Поле | Что значит |
| --- | --- |
| `branch` | Ветка, из которой берётся код. Только `Ilya/…`, `Stas/…`, `pavel/…`, `Nikita/…`. |
| `command` | Что запустить (см. ниже). |
| `gpus` | `0`, `1` или `2`. Всего на машине доступно 2 карты — на всех. |
| `timeout_minutes` | От 1 до 120. По истечении запуск убивается вместе со всеми потомками. |

`run_id` — это имя файла без `.yml`. **Повторно использовать имя нельзя:**
диспетчер узнаёт по нему уже отработавший запуск и просто не возьмёт спеку в
работу. Для нового прогона заведите файл с новым именем. Удобно начинать имя со
своего — так каталоги результатов не перемешиваются.

## Какие команды разрешены

Команда выполняется напрямую, **без shell**. Разрешены формы:

```
python  <скрипт.py> [аргументы]
python3 <скрипт.py> [аргументы]
bash    <скрипт.sh> [аргументы]
sh      <скрипт.sh> [аргументы]
uv run python <скрипт.py> [аргументы]
uv run kedro run --env experiments/<имя> [аргументы]
```

Скрипт обязан быть **закоммичен в репозиторий на указанной ветке**: файл, лежащий
только у вас на диске или попавший в `.gitignore`, не подойдёт.

Не работают и будут отклонены:

- `;`, `|`, `&&`, `$(...)`, обратные кавычки, `>` — shell не участвует, поэтому
  такие символы всё равно ничего бы не сделали. Нужна цепочка команд — положите
  её в `.sh`-скрипт и закоммитьте;
- `python -m module` и `python -c '...'` — нужен путь к скрипту;
- любые другие программы (`curl`, `make`, `pip`, …).

## Что доступно запуску

Команда выполняется в песочнице (bubblewrap): файловая система видна целиком,
но на запись доступны только рабочая копия запуска и общие кэши.

- рабочая копия репозитория на коммите вашей ветки — в неё можно писать;
- `CUDA_VISIBLE_DEVICES` с номерами выданных карт;
- общий кэш моделей `HF_HOME` и кэш пакетов `UV_CACHE_DIR` — Qwen уже скачан,
  качать заново не нужно;
- `MATHAGENT_RUN_ID` — тот самый `run_id`, удобно передавать в `--run-id`.

Ключей и токенов в окружении нет. Локальный vLLM отвечает на
`http://127.0.0.1:8000/v1` с `--api-key EMPTY`.

## Что публикуется

Всё, что запуск записал в `results/`, плюс `results/runs/<run_id>/runner.log` с
выводом команды. Файлы больше 90 МиБ пропускаются — GitHub их не принимает; о
пропуске будет сказано в комментарии к PR.

## Очередь

- всего 2 карты, поэтому одновременно идут максимум два однокарточных запуска;
- порядок — по времени вливания PR;
- если первой в очереди не хватает карт, очередь ждёт её, а не пропускает
  вперёд следующих. Двухкарточный запуск не будет висеть вечно за чужими
  однокарточными;
- запуски без GPU (`gpus: 0`) в очереди не стоят.

## Частые ошибки

| Сообщение в комментарии | Что делать |
| --- | --- |
| `branch ... not found` | Запушить ветку до вливания PR. |
| `branch ... must start with one of` | Переименовать ветку под свой префикс. |
| `... is not tracked in the repository` | Закоммитить и запушить скрипт. |
| `command contains shell metacharacters` | Перенести логику в `.sh`-скрипт. |
| Спека влита, но ничего не произошло | Имя файла уже использовалось — взять новое. |
